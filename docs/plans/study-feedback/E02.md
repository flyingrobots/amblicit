## 2. Problem Description

The create provider reads known configuration fields without rejecting every unknown field. A new key-limit field can be ignored. The runtime sees a derived node hash unless canonical key input remains available.

## 2b. Proposed Solution

Define a versioned, digest-bound key-limit contract with Unicode-scalar units. Corroborate it against the exact Core input type in lowerer and verifier. Preserve canonical key input through invocation. Enforce its limit before mutation. Require provider capability/version admission so an older provider cannot silently claim support.


### Current-source reconciliation and execution sequence

The current-source reconciliation used Echo revision `c144123559d8f9ac1368e929695e815f6ecbc075`. Inspection confirms the flaw but refines the proposed transport work: projected invocations already retain canonical application input. `EchoOperationApplicationResultProjectionV1::validate_application_input_binding` decodes canonical text and checks its SHA-256 against the invocation node, but does not count Unicode scalars (`crates/warp-core/src/echo_operation.rs#1204` at that SHA). Static invocation admission calls that validator before admission succeeds (`#3290`). Reuse this retained input and refusal boundary rather than introducing another input channel.

Both native provider configuration readers still use the v1 configuration ABI and omit a scalar key limit (`crates/echo-edict-provider-lowerer/src/executable_operation.rs#1092`; independent verifier `#1140`, same SHA). The package currently encodes a replacement byte bound but no declared key scalar bound. Preserve exact old package bytes and make the bounded claim opt-in through a versioned configuration and a distinct runtime-supported profile. The exact new identifiers and schema fields require a compatibility check against the producer/component generation machinery before implementation; this is a proposed design, not shipped behavior.

1. Establish the current shared Echo worker/output budget and fail-closed guard before any build. Existing `echo-provider-builder` and `echo-read-runtime` workers are present; do not create parallel workers or caches merely for this branch.
2. Write the smallest runtime admission witness: declared maximum 64 accepts 64 ASCII and 64 four-byte scalars, rejects 65 before mutation, and rejects empty/missing/invalid UTF-8 or substituted key input. Retain legacy acceptance/bytes as a separate control.
3. Add a digest-bound bounded-key runtime contract and count scalars from retained canonical text before successful invocation admission. Keep absolute byte caps and nonempty rules explicit and distinct from the scalar limit.
4. Extend the lowerer and structurally independent verifier to derive/corroborate the selected key field's bound against the exact Core input type and emit the bounded contract. Rehashed forged-limit and substituted-path fixtures must fail independent verification.
5. Update configuration/schema capability selection and reproducibly build/promote matched components. Exercise an older provider against the new configuration and require refusal; never add an ignored optional field to the old claim.
6. Run public compiler → independent verifier → admission → execution/replay witnesses, update canonical owners and CHANGELOG, and perform documentation accuracy and PR gates. Obtain independent agy review when available before merge.

## 2d. Acceptance Criteria

Accept 64 scalars and refuse 65 before mutation. Cover 64 four-byte scalars, invalid UTF-8, missing key, substitution, and forged limits. Define nonempty and absolute key byte caps separately. Older provider/configuration combinations refuse the new bounded contract or remain explicitly legacy without the new claim.

## 2e. Test Plan

Golden: independently verified projected execution. Edges: metadata substitution, invalid input, authority failure, stale basis, and callback-free recovery. Known failure modes: lowerer/verifier disagreement or unsupported metadata ignored by a legacy provider. Fuzz and stress: deterministic bounded witnesses under Echo resource guards.
