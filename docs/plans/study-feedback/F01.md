## 2. Problem Description

Intents without source functions skip the output-budget check. A bounded return type can exceed maxOutputBytes.

## 2b. Proposed Solution

Calculate a safe canonical-CBOR size bound for every ordinary result. Include fixed-width integer limits, UTF-8 expansion, CBOR headers, record keys, lists, and nominal representations. Reject an excess or overflow with InvalidBound.
Preserve the separate request-only protocol contract. Reject opaque request shapes nested in ordinary results with UnsupportedSourceShape. Document both boundaries.
Keep the check and required fixture corrections in one PR. The stock lawpack generator compiles witnesses before output. A check-only merge would reject those positive witnesses.
Raise only fixture budgets whose declared outputs cannot fit. Preserve their type contract and runtime byte caps. Regenerate the complete dependent digest closure. Keep old producer pins intact. Document intentional new digests and migration limits.

## 2c. Alternatives considered and rejected

Leave the limitation undocumented: authors cannot identify the contract boundary.
Combine unrelated fixes: a reviewer cannot verify one outcome independently.

## 2d. Acceptance Criteria

Reject an oversized ordinary return without source functions. Accept exact fit and reject one byte below it. Cover nested records, lists, nominal types, Unicode, and arithmetic overflow. Preserve request-only protocol output and source-function refusal behavior.
Run the public canonical encoder on a worst-case Unicode record. Verify the 16,662-byte maximum independently. Reconcile Hello and both cell fixtures. Fix the experimental byte_concat parser error and projection expectation before candidate readiness.
Run complete syntax, workspace, and cargo xtask verify gates. Show only intentional golden differences. Retain frozen old producer witnesses and state new-compiler/old-lawpack limitations.

## 2e. Test Plan

Golden: exact-fit and under-budget results. Edges: CBOR header transitions and four-byte Unicode scalars. Known failure modes: size overflow and unsupported representations. Fuzz and stress: none; deterministic boundary cases suffice.
