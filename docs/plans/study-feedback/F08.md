## 2. Problem Description

The causal-cell type limits the key to 64 Unicode scalar values. Its target configuration carries a replacement-byte bound but no key bound. Echo does not perform general input-schema validation.

## 2b. Proposed Solution

After E02 merges, bind an explicit Unicode-scalar key limit to the compatible provider configuration and exact Core input type. Use the reviewed schema/capability version. Regenerate the canonical closure and update only source imports that intentionally select it.
The existing create configuration parser can ignore unknown fields. Metadata alone gives no runtime protection. Older components must refuse the new bounded contract or retain an explicitly legacy posture. Preserve raw UTF-8 key identity and the old pinned witness.
