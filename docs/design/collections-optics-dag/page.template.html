    Why the largest wave and the maximum antichain differ

    Kahn waves place tasks in their earliest dependency layer. A later frontier can combine tasks from different layers. The maximum antichain is computed exactly from reachability and is certified by an equally sized chain cover; it is not estimated from the largest wave.

        How to read this map

        Read left to right. An arrow from A to B means A's required work must be complete before B can be complete. Each executable issue is intended to land as one coherent PR. Position expresses dependency depth, not time, effort or a delivery date.

        Project buttons and search spotlight tasks while keeping the surrounding map visible. Select a task, then choose its prerequisites, dependents or whole chain to isolate that part of the graph. A focused view never invents shortcut arrows. The List view filters to matching tasks and always names their direct prerequisites.

        An entry task has no recorded prerequisites in this snapshot; that is not a merge-readiness claim. The roadmap container and parent/child grouping are excluded from the task graph. This is a dated, offline snapshot; GitHub remains the live source.

        Keyboard: / search, +/− zoom, 0 fit, Esc clear, arrow keys pan when the map has focus. Task cards and dependency-list buttons are keyboard accessible.
